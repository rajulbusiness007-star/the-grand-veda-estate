## 🏰 Overview

**The Grand Veda Estate & Celebration Resort** is a luxury 5-star palatial retreat and celebration venue in Nashik Valley. Built with **React 19**, **Vite**, **Tailwind CSS v4**, and **Lucide Icons**, it features high-fashion editorial aesthetics, romantic calligraphy typography, interactive decor customizers, and palatial booking workflows.

### ✨ Key Features
- **Editorial Hero Slideshow**: 7 bespoke slides with romantic cursive script typography (`Great Vibes`), frosted glass emblem badges, and floating warm bokeh fairy light animations.
- **Knot & Plot Event Atelier**: Dedicated tablescape showcase with interactive inspection hotspots, 3 styling packages, and custom decor previewers.
- **Interactive Tablescape Styler Modal**: Real-time preview of Gazebo Canopies (*Blush Rose & Chiffon, Royal Marigold*), Seating (*Gold Chiavari, French Louis Cane*), and Illumination (*Fairy Bokeh Chandeliers, Hurricane Candles*).
- **Events & Heritage**: Palatial pillars for Royal Lawns (up to 1,500 guests), Crystal Ballroom (600 guests), and Presidential Bridal Suites.
- **The Finer Details**: Artisanal deckle edges, 3D wax seals, and olive silk ribbon motifs.
- **Interactive Celebration Quote Calculator**: Instant quotes for weddings, anniversaries, and receptions with catering menu breakdowns.
- **Palatial Accommodations**: 48 luxury heritage rooms and suites with interactive modal booking.

## 🚀 Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Open in browser
# http://localhost:3000/#home
```

## 🛠️ Tech Stack
- **Framework:** React 19 + Vite 8
- **Styling:** Tailwind CSS v4 + PostCSS
- **Icons:** Lucide React
- **Fonts:** Cormorant Garamond, Great Vibes, DM Sans, Plus Jakarta Sans
